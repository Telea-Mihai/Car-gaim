# Car game - Demo

A unity project with the scope of creating a fun and exciting driving experience.

It currently features:

 - a comprehensive sim-cade car controller based on unity wheel colliders
 - a simple race builder, with a tool for generating a optimal racing line to assist the racing NPC's
 - racing NPC's that are aware of obstacles on the road and other vehicles, capable of prediciting incoming danger and acting accrodingly
 - a simple crash system with deformable car bodies and removable parts
 - engine and drivetrain simulation
 - module based assists (Toggable ABS, TC, ESC)
 - a dynamic camera that gives a sense of speed
